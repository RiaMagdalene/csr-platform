# ATLAS — CSR Intelligence Platform

> Direct capital where it matters.

ATLAS is a CSR intelligence platform designed to make corporate social investment more targeted and explainable.

The platform maps district-level development needs, identifies opportunity gaps, and matches priority districts with NGOs based on geography, sector alignment, and organisational capacity.

## 🚀 Live Demo

[Open ATLAS](https://csr-platform-sepia.vercel.app/)

## 🗺️ Tamil Nadu Pilot

- 20 districts mapped
- District-level need index
- CSR allocation analysis
- Opportunity gap scoring
- Explainable NGO matching

## ✨ Core Features

### Discover
Explore district-level development signals across the Tamil Nadu pilot.

### Prioritize
Identify areas where high need and relatively lower CSR allocation create greater opportunity.

### Plan
Match priority districts with organisations capable of delivering locally relevant work.

### Track
Future-ready foundation for impact goals, watchlists, and portfolio-level CSR planning.

## 📌 Project Scope

ATLAS currently focuses on need mapping and NGO matching across a 20-district Tamil Nadu pilot.

The platform is designed to be extensible toward personalized impact portfolios, impact goals, watchlists, and broader CSR planning.
